# Do It Yourself Lisp

Проект состоит из двух частей: самостоятельного языка Lisp и игры, которая использует этот язык для управления магами.

```text
lisp  ←  wizard_game
```

Зависимость направлена только в одну сторону. Интерпретатор ничего не знает об арене, заклинаниях и `pygame`; игру можно удалить, и пакет `lisp` продолжит работать целиком.

## Установка

Нужен Python 3.10 или новее. Графическая оболочка использует `pygame-ce`, импортируемый как обычный `pygame`.

```text
python -m pip install -e .
python -m unittest discover -v
```

# Интерпретатор Lisp

Код языка находится в каталоге `lisp`. В учебных материалах он назывался компилятором, хотя его текущая модель работы — интерпретация: парсер строит S-выражения, а вычислитель исполняет их в лексическом окружении.

Интерпретатор запускается независимо от игры:

```text
python -m lisp
```

Его также можно использовать как обычную библиотеку:

```python
from lisp import Interpreter

lisp = Interpreter()
result = lisp.execute("(+ 20 22)")
```

## Синтаксис языка

`nil` обозначает ложь и пустой список. Любое другое значение истинно. Строки записываются в кавычках, символы — без них.

```lisp
(define (factorial n)
  (if (= n 0)
      1
      (* n (factorial (- n 1)))))

(factorial 6)
```

Ядро поддерживает `quote`, `if`, `cond`, `define`, `set!`, `lambda`, `let`, `let*`, `begin`/`progn`, `and`, `or` и `try`. В стандартном окружении есть арифметика, цепочки сравнений, операции со списками и функции высшего порядка.

```lisp
(let ((x 2) (y 3)) (+ x y))
(map (lambda (x) (* x x)) '(1 2 3))
(try (/ 1 0) (lambda (message) message))
```

Квадратные скобки создают вычисляемый вектор, фигурные — словарь. Это расширения языка, а не замена Lisp-списков.

```lisp
[1 (+ 1 1) 3]
{"name": "Мерлин" "health": 100}
```

Внутри пакета отдельно лежат токенизация и парсинг, окружения, вычислитель, ошибки и стандартные функции. Ни один из этих модулей не импортирует `wizard_game`.

# Игра «Битва магов»

Игра находится в каталоге `wizard_game` и запускается отдельно:

```text
python -m wizard_game
```

`model.py` содержит правила дуэли без зависимости от Lisp и `pygame`. `scripting.py` подключает игровые команды к двум независимым экземплярам интерпретатора. `pygame_app.py` отвечает только за окно, терминал и эффекты.

Текстовый режим оставлен как дополнительный ручной интерфейс:

```text
python -m wizard_game.cli
```

## Подготовка стратегий

Графическая игра начинается с последовательного ввода двух стратегий.

1. Терминал принимает исходник стратегии Гэндальфа.
2. Команда `finish` проверяет синтаксис и наличие функции `(turn)`.
3. Терминал переключается на стратегию Мерлина.
4. Второй `finish` запускает дуэль автоматически.

Фрагменты можно вводить вручную:

```lisp
(define (turn)
  (if (and (visible?) (< (distance) 5))
      (cast "огненный шар"
            (get (enemy-position) 0)
            (get (enemy-position) 1))
      (move 1 0)))
```

После этого вводится:

```text
finish
```

Готовые примеры загружаются так:

```text
load examples/gandalf.lisp
finish
load examples/merlin.lisp
finish
```

До `finish` исходник только собирается. Игровые действия на верхнем уровне заблокированы, поэтому ошибочный `(move ...)` не изменит арену. Неудачная проверка также не переключит терминал на следующего мага.

Дополнительные команды подготовки:

- `strategy` — показать собранный исходник;
- `reset-strategy` — очистить текущую стратегию;
- `manual` — отказаться от стратегий и перейти к ручным ходам.

## Игровые функции Lisp

Каждый вызов `(turn)` может выполнить не более одного действия. Вычисления, условия и просмотр состояния ход не расходуют.

```lisp
(move dx dy)
(select-spell "молния")
(cast "молния" x y)

(health)
(mana)
(position)
(enemy-health)
(enemy-position)
(distance)
(visible?)
```

Старые формы команд также поддерживаются, но имя должно принадлежать текущему магу:

```lisp
(move-wizard "Гэндальф" [1 0])
(cast-spell "Гэндальф" "огненный шар" 10 7)
```

У магов разные окружения. Определения, переменные и замыкания одной стратегии недоступны другой. Командовать противником из своей стратегии нельзя.

## Управление окном

- `Enter` — добавить фрагмент или выполнить команду;
- `Shift+Enter` — добавить строку в поле ввода;
- `↑` и `↓` — история текущего мага;
- `Ctrl+V` — вставка;
- `PageUp` и `PageDown` — прокрутка терминала;
- `F1` — справка;
- `auto` — остановить или продолжить уже подготовленный бой;
- `restart` — начать заново с ввода стратегии Гэндальфа.
